- [patch] REM model assist review decisions, closing the remaining findings of the Native partner's design review (2026-11-01). (1) An extractive digest no longer stays extractive forever: while assist is active the planner also re-plans a family whose current digest is extractive at the same source generation (`upgradeExtractive`, ordered after new and changed families), and only an accepted model rewrite replaces it; a failed attempt leaves the digest untouched and never rewrites it with the same text. (2) The output validator refuses every URL and backtick span, even one present in a source note, and the prompt says so, because notes are untrusted. (3) A legacy digest without a generation fingerprint never reaches the model, since a rewritten text could not bind to it. Accepted limits: the daily call budget resets on restart, there is no per-family backoff for failing upgrades (the budget bounds the waste), and the provider path has no output-token parameter, so length is bounded by validation only.
