# Agent Core — Maintenance Backlog

> **Created:** 2026-09-17
> **Scope:** Native Agent Core memory subsystem audit findings.
> **Embedding model decision:** Keep the current Cloudflare Workers AI `@cf/google/embeddinggemma-300m` (768 dimensions). No model replacement is planned; the items below concern Agent Core memory plumbing, durability, correctness, semantics, and coverage.
> **Status:** Open maintenance findings; not yet fixed unless explicitly updated here with verification evidence.

| Severity | Temuan | Evidence |
| --- | --- | --- |
| **HIGH** | **Cross-process memory lock dapat kehilangan mutual exclusion.** Lock dianggap stale setelah 30 detik tanpa melihat bahwa PID lokal masih hidup. Selain itu dua contender yang mencoba mengambil stale lock bisa sama-sama sempat lolos: keduanya melakukan `rename(temp, lockPath)` lalu masing-masing hanya mengecek token setelah rename. Ada race di mana contender A membaca tokennya dan masuk critical section sebelum contender B menimpa lock dan ikut masuk. | `src/memory/lock.ts:14`, `:33-34`, jalur `claim()` sekitar `:51-68` |
| **HIGH** | **Semantic index dapat stale terhadap canonical memory.** `search()`, `evolve()`, dan `consolidate()` melakukan `reload()` canonical, tetapi tidak `ensure()` index setelah reload. Jadi perubahan dari proses lain atau direct filesystem dapat membuat lexical memakai content baru sementara vector masih mewakili content lama. | `service.ts:422-432`, `:470-487`, `:519-523`; `index.ts:147+` |
| **HIGH** | **`/health` memory bukan live truth setelah startup.** `health()` hanya mengembalikan cached state. `/health` memanggil `memoryService.health()` tanpa reload/validation. Kalau bootstrap/index dihapus atau rusak setelah startup, status masih dapat tetap `available`. Bahkan jika `index.json` hilang, `semanticContext()` bisa return `null` tanpa menandai degradation. | `service.ts:195-211`; `index.ts:147-154`; `src/index.ts:56+` |
| **MEDIUM** | **`budgetChars` tidak benar-benar membatasi hasil pertama.** Kondisi `if (budgeted.length && ...)` berarti result pertama selalu masuk meskipun jauh di atas budget. Dengan content maksimum 200k, default budget 20k bisa menghasilkan response ratusan ribu karakter. | `retrieval.ts:118` |
| **MEDIUM** | **Validasi persisted embedding terlalu lemah.** `MemoryIndex.ensure()` hanya memastikan `embedding` adalah array. Tidak memvalidasi dimension, finite numeric values, atau shape. Index rusak bisa dianggap `embedding=available` tetapi cosine diam-diam menjadi 0/NaN atau semantik mati. | `index.ts:135-143`, `:153`, `:162`, `:171` |
| **MEDIUM** | **`semanticSimilarity` sebenarnya bukan similarity.** Nilainya adalah cosine × 4, sehingga dapat menjadi `2.9`, `3.8`, dst. Nama field membuat controller mengira range 0–1. Ini sudah terlihat pada acceptance sebelumnya. | `retrieval.ts:63` |
| **MEDIUM** | **Relationship evolution tidak memperkuat link existing dan bersifat satu arah.** `existingTargets` membuang proposal untuk target yang sudah terhubung; `normalizeLinks()` mempertahankan link pertama. Jadi link strength tidak pernah diperbarui oleh intelligence. `related` yang dibuat pada memory baru juga tidak dibuat reciprocal pada neighbor. | `intelligence.ts:77-81`; `evolution.ts:51`; `relations.ts:3-14` |
| **MEDIUM** | **`review-supersedes` tidak punya bukti supersession.** Semua candidate dengan combined score <0.9 otomatis dilabel `review-supersedes`, padahal algorithm hanya tahu similarity/overlap dan tidak menentukan mana yang menggantikan mana. Ini semantik yang menyesatkan. | `consolidation.ts:74` |
| **LOW** | **MCP schema dan service contract tidak sinkron untuk link timestamp.** Service sengaja membuat `createdAt` optional dan akan mengisinya sendiri, tetapi MCP schema mewajibkan client mengirim `createdAt`. | `service.ts:14`, `:64+`; `memory-schemas.ts:3-8` |
| **COVERAGE GAP** | Test otomatis memory saat ini terlalu sempit untuk durability claims. Yang benar-benar menguji `MemoryService` hanya `memory-phase8-10.test.ts` dengan 2 test utama. Tidak ada dedicated regression untuk memory lock, concurrent writers, CRUD Phase 1–7, malformed notes, delete/link repair, stale index, health drift, atau hard budget. | pencarian seluruh `tests/` |
