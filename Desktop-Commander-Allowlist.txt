# External Remote Desktop Commander - dynamic folder allowlist (separate from Agent Core runtime)
# This file configures only the external RDC operator tool. It is not an Agent Core filesystem policy or Agent Core health/acceptance surface.
# No fixed drive letters: this external-tool allowlist must survive moves between drives/machines.
# Supported dynamic tokens:
#   @PROJECT_ROOT   = current Agent Core project folder
#   @PROJECT_DRIVE  = drive that currently contains Agent Core
#   @SYSTEM_DRIVE   = current Windows system drive
#   @FIXED_DRIVES   = every ready local fixed drive on the current machine
# Relative paths are resolved from the current Agent Core project root.

# Preserve broad local-machine access without hardcoding C:/E:/F:.
@FIXED_DRIVES

# Examples:
# @PROJECT_ROOT
# @PROJECT_DRIVE
# .
# "..\Shared Assets"
