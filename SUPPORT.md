# Support

Use this repository's Issues for reproducible Agent Core bugs, recovery problems, documentation gaps, and scoped feature requests.

Before opening an issue:

- Confirm whether the problem is Agent Core or the separate external Remote Desktop Commander tool.
- Capture the exact error message and affected path/tool.
- Include Agent Core version and relevant environment information.
- Remove API keys, OAuth tokens, passwords, device identifiers, and other secrets.
- Do not upload `.env`, `secrets/`, runtime auth stores, browser profiles, or raw private memory.

For security-sensitive reports, follow [SECURITY.md](SECURITY.md) instead of posting exploit details in a normal issue.

For architecture questions, start with [docs/CODEBASE.md](docs/CODEBASE.md).
