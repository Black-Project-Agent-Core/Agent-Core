# Code of Conduct

This repository is maintained as a professional engineering workspace.

Participants are expected to:

- communicate directly and respectfully;
- focus criticism on code, evidence, behavior, and technical tradeoffs;
- avoid harassment, personal attacks, discrimination, threats, or deliberate disruption;
- protect private information and credentials;
- respect repository boundaries and explicit authorization requirements;
- report security concerns through the security process rather than exposing them publicly.

Repository owners may remove content or access that violates these expectations.

For security-sensitive matters, see [SECURITY.md](SECURITY.md).
