# Agent Code

Agent Code is a Windows-oriented desktop coding-agent shell. Milestone 1 intentionally builds only the premium Focused Console interface and local interaction model.

Super-Runtime, model execution, shell/process execution, authentication, remote services, persistence, and AI responses are deliberately absent from this milestone.

## Development

Commands will be available after dependency installation:

```bash
npm run dev
npm test
npm run typecheck
npm run build
```
