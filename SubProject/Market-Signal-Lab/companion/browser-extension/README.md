# Market Signal Lab Visible Ranking Capture

Load this unpacked Manifest V3 extension in Chrome or Edge. It only reads ranking cards that are currently rendered and visible after you press **Capture visible ranking**. It never performs background collection or scrolling, and it never reads cookies, tokens, passwords, browser storage, or request headers.

1. Open `chrome://extensions` or `edge://extensions`.
2. Enable Developer mode.
3. Choose **Load unpacked** and select this folder.
4. Open a supported Envato listing page and set its sort/filter state.
5. Open the extension, choose the observation context, then capture.
6. Review and confirm the pending preview inside Market Signal Lab.
