**Interfaces:**

Keep the existing `Engine` numerical interface. Extend current `EngineStatus` rather than adding a second competing health type:

```go
const (
    EngineStarting         EngineStatus = "starting"
    EngineHealthy          EngineStatus = "healthy"
    EngineUnavailable      EngineStatus = "unavailable"
    EngineProtocolMismatch EngineStatus = "protocol_mismatch"
    EngineCrashed          EngineStatus = "crashed"
    EngineTimedOut         EngineStatus = "timed_out"
    EngineInvalidResult    EngineStatus = "invalid_result"
)

type ProductionRuntime struct {
    engine Engine
}

func NewProductionRuntime(ctx context.Context, workerPath string, timeout time.Duration) *ProductionRuntime
func (r *ProductionRuntime) Engine() Engine
func (r *ProductionRuntime) Health(ctx context.Context) Health
func (r *ProductionRuntime) Close() error
```

`ProductionRuntime.Engine()` always refers to the Rust production engine. There is no mode argument.
