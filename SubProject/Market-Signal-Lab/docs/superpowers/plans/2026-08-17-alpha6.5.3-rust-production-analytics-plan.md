# Alpha 6.5.3 — Rust Production Analytics Cutover Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Convert Alpha 6.5.3 from a selectable Go/Rust/fallback experiment into a production architecture where Go remains the Market Signal Lab control plane and a packaged Rust worker is the sole production implementation for migrated analytics.

**Architecture:** Preserve the Go application host, Envato scanner, storage, security, HTTP/SSE, telemetry, localization, and domain/provenance orchestration. Replace production `GoEngine`, `RustFallbackEngine`, `ShadowEngine`, and `EngineMode` selection with one mandatory Rust production runtime over long-lived versioned NDJSON. Freeze Alpha 6.5.2.1 numerical behavior into test-only reference vectors so migration can prove compatibility without keeping a hidden production Go analytics path.

**Tech Stack:** Go 1.22+, Rust stable/Cargo/Clippy, serde/serde_json, NDJSON stdin/stdout IPC, existing HTML/CSS/vanilla JavaScript UI, append-only JSON/JSONL local history, Windows x64 packaging.

## Global Constraints

- Project scope remains market **Trends & Insights** only.
- No personal portfolio/review/rejection/submission intelligence in this phase.
- No Go production analytics fallback after cutover.
- No user-selectable `Go Native`, `Rust Native`, or `Shadow Verification` production modes.
- Rust worker must be real, compiled, packaged, and health-checked.
- Worker absence/crash/timeout/protocol mismatch must be explicit and must not publish a substituted Go analytics result.
- Existing stable analytics must match frozen Alpha 6.5.2.1 reference evidence within declared tolerances.
- Rust receives normalized analytical input only; never Envato token, Authorization header, cookies, browser storage/session, account data, or credential-bearing raw API payloads.
- Runtime demo/synthetic market-data controls must be removed.
- Synthetic fixtures are allowed only under tests/benchmarks/research and must never enter runtime history/UI.
- English/Indonesia exact key parity remains a release gate.
- Existing Alpha 6.5.2.1 real history/storage must remain readable.
- Existing Market Surface != Catalog, temporal Date A/Date B, telemetry, provenance, and Browser Companion contracts must remain intact.
- Safe source/docs/tests/QA/checkpoint files must be synchronized to `rendevouz999/Market-Signal-Lab` before handoff.
