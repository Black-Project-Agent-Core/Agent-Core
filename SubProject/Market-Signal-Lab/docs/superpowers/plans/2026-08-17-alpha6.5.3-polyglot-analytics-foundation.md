# Alpha 6.5.3 — Polyglot Analytics Foundation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace selected deterministic numerical kernels that currently live in Go with an optional Rust analytics worker while keeping Go as the stable host, reference implementation, and automatic fallback.

**Architecture:** Market Signal Lab remains a Go application. A new `internal/analyticsengine` boundary owns numerical analytics contracts. `go-native` implements the same formulas in-process; `rust-native` invokes a long-lived Rust worker through versioned NDJSON over stdin/stdout; `shadow` computes with both engines and publishes the Go result unless Rust passes parity tolerance. Rust never reads storage or credentials directly.

**Tech Stack:** Go 1.22+ host, Rust stable + Cargo worker, serde/serde_json in Rust, NDJSON process IPC, vanilla JavaScript/HTML/CSS for diagnostics UI, existing JSONL persistence, Windows x64 packaging.

## Global Constraints

- Preserve Go as the application host/orchestrator, HTTP/SSE server, Envato connector, storage owner, telemetry owner, and security boundary.
- Do not rewrite scanner, Market Autopilot, storage, Browser Companion, or web server in Rust.
- Rust pilot scope is limited to: cross-surface distribution similarity, ranking volatility math, and observed selection probability math.
- Existing Go consensus/domain outputs, model labels, IDs, timestamps, provenance, and storage formats remain backward-compatible.
- Go remains the default engine and the fallback source of truth.
- Rust receives only normalized mathematical inputs; never Envato tokens, Authorization headers, cookies, browser storage, account data, raw HTML, or raw API bodies.
- IPC protocol is versioned as `msl-analytics/1` and every request/response carries a request ID.
- Rust failure must never prevent MSL startup or destroy an existing market-analysis result.
- Shadow Verification must record parity deltas without changing published market outputs.
- English and Indonesia remain release-gated.
- No mock market data is added to runtime.
- README remains evergreen product documentation; detailed version/change information belongs in CHANGELOG and GitHub Releases.

package analyticsengine

type Capability string

const (
    CapabilityDistributionSimilarity Capability = "distribution_similarity"
    CapabilityItemVolatility         Capability = "item_volatility"
    CapabilityClusterVolatility      Capability = "cluster_volatility"
    CapabilitySelectionProbability   Capability = "selection_probability"
)

type Engine interface {
    Name() string
    Version() string
    Capabilities() []Capability
    Health(context.Context) Health
    DistributionSimilarity(context.Context, DistributionSimilarityInput) (DistributionSimilarityResult, error)
    ItemVolatility(context.Context, ItemVolatilityInput) (VolatilityResult, error)
    ClusterVolatility(context.Context, ClusterVolatilityInput) (VolatilityResult, error)
    SelectionProbability(context.Context, SelectionProbabilityInput) (SelectionProbabilityResult, error)

}

## Acceptance Criteria

1. Existing MSL can run with no Rust worker using `go-native` exactly as before.
2. `rust-native` produces parity-equivalent results for all three pilot analytics areas within declared tolerances.
3. `shadow` never changes published market results; it only verifies Rust against Go.
4. Worker crash/timeout cannot crash MSL; fallback to Go is automatic.
5. Rust worker has no direct access to MSL storage or credentials.
6. Existing Alpha 6.5.2.1 JSON/history formats remain readable.
7. Windows package contains both executables without requiring Rust installation on the user machine.
8. Settings can show engine health and diagnostics in English and Indonesia.
9. Benchmark evidence is recorded but does not silently change the default engine.
10. Runtime contains no synthetic market data.

## Deferred Explicitly

- Moving Envato HTTP/scanner code to Rust.
- Moving JSONL storage to Rust.
- C++ worker implementation.
- Python production runtime.
- Market Flow/Cohort features.
- Trend State, Historical Echo, Seasonality, and Probability Calibration.
- Making Rust the default engine before real parity/benchmark evidence exists.
