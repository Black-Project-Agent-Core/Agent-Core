# Market Signal Lab v0.3 Alpha 6.5.2.1 — Live Scan Telemetry & Adaptive ETA Implementation Plan

> **Historical record:** this document preserves its original design/release revision, paths and evidence. It is not a current execution checklist or fresh verification. See [current continuation](../checkpoints/CONTINUE_MSL.md) for the imported monorepo boundary; unavailable historical source links are not silently reconstructed.

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add factual live scan progress, structured process/error telemetry, persisted runtime history, and an adaptive deterministic ETA to Market Autopilot while preserving Alpha 6.5.2 Trends & Insights behavior and the approved responsive UI.

**Architecture:** The Go server owns scan execution and telemetry truth. A new telemetry package records canonical stage/work-unit events, persists append-only event/runtime history, and produces ETA estimates from current-run rates plus structurally comparable historical runs. `Map Market Now` becomes asynchronous: the POST returns a run identity immediately, the browser loads a live snapshot and subscribes to Server-Sent Events, and finalized analytical results remain separated as `Last Completed Map` until the current run completes. Existing Envato connector, ranking, consensus, Signal Integrity, and Browser Companion behavior remain unchanged.

**Tech Stack:** Go, `net/http`, append-only JSONL storage, embedded HTML/CSS/JavaScript, Server-Sent Events, existing English/Indonesia i18n registry, existing responsive workspace, Windows x64 cross-build.

## Global Constraints

- Keep Alpha 6.5.2 market-analysis scope: Trends & Insights only; do not add personal-item review/rejection scoring.
- No AI, LLM, embeddings, Ollama, GPU, or cloud inference.
- No mock/synthetic runtime market data.
- Progress must be computed from current-run planned/completed work units, never previous product counts.
- Quick/Standard/Deep may define scan topology but must not hard-code ETA duration.
- If a reliable denominator is not yet known, progress is indeterminate rather than fabricated.
- If ETA evidence is insufficient, display `Calibrating…` / `Mengkalibrasi…` rather than a fake precise time.
- English is default/fallback; Indonesia is second. Every new translation key must have exact parity.
- Preserve `%LOCALAPPDATA%\MarketSignalLab\` compatibility.
- Never persist or render Envato personal token, Authorization headers, cookies, browser storage, account email, raw HTML, or raw API bodies.
- Existing Cross-Surface Consensus formulas, Trend/Opportunity formulas, Data Quality, Coverage, Confidence, Temporal Product Intelligence, and Browser Companion contracts must not change.
- Approved visual concept: `market_autopilot_analytics_dashboard.png`; the implementation must preserve the Alpha 6.5.2 responsive shell while adding the Live Market Mapping panel, recent-log panel, stage tracker, progress bar, runtime metrics, and explicit `Last Completed Map` section.
