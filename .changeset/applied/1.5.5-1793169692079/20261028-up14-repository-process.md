Repository process and developer documentation. A new `agent_behavior` issue form asks which controller acted, the tool grant in effect, what was changed versus only read and whether AGENTS.md was broken, with no link that puts data into a query string. `.gitattributes` now marks `runtime/skills/**` as `-text`, because Skill artifacts are identified by the digest of their exact bytes and 24 tracked files carry CRLF; a repository-wide line-ending normalization was checked and is not safe. The Cloudflare tunnel guide gains a table for reading probe results (a `401` from `/mcp` is a healthy endpoint), and a new guide explains the `servers.json` format for extra language servers with its Windows limits.
