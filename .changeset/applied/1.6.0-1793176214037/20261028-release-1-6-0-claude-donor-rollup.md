Release 1.6.0 closes the Claude ecosystem donor work (proposal packages UP-01 to UP-14, released one by one as 1.0.0 to 1.5.14) as one version. The `changed_source` scanner is truthful about its coverage and limits, and the Claude plugin adapter reports what real plugins contain. On Windows the process tool refuses an invalid PID, Agent Core's own process and its parent, a narrow guard refuses catastrophic deletes, file reads decode UTF-8 strictly and recognize UTF-16, and git reads reject option-like references. The Native loop reads why a reply ended, never runs a truncated tool call and names failures by cause. Text from outside is treated as data: invisible and bidirectional control characters are removed from labels built from it, key-shaped secrets are redacted without a label, credential file name variants are recognized, the Memory safety scan flags personal identifiers, and dynamic OAuth client registration is limited to 20 per minute and 50 unauthorized clients. New read-only evidence tools cover the Skill pack lint with trigger overlap, a test-run verdict computed from counts, the always-loaded instruction audit, a work receipt from the Activity Tracker, and an explicit upstream drift report. Activity Tracker outcome defects are fixed. Fourteen reference deltas for ten Skills are staged and two new Skills (`windows-powershell-host`, `skill-authoring`) ship as sources; nothing staged is promoted. The README, release notes and documentation guides are updated, a UI theme contrast test is added and `link.txt` is removed. No benchmark was run and the full root test suite was not run; verification was targeted per package.
