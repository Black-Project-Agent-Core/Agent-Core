Process and command guards for the Windows host. `start_process` refuses a catastrophic delete (drive roots, the user profile and Users folder, the Windows and Program Files folders, ProgramData, and the Agent Core project folder or the folder that holds it) with a message that says how to run it personally, and it adds an advisory when a command mentions an auto-run location (PowerShell profile, Startup folder, git hook, Run key, scheduled task). The command blocklist now sees `reg.exe` as `reg`, quoted paths with spaces, the `&` call operator and newline-separated commands. Terminal output is decoded per stream so a multi-byte character split across chunks stays intact, ANSI escape sequences are stripped, `NO_COLOR` is set for child shells, and a crash exit code is named (for example `STATUS_ACCESS_VIOLATION`). Protected-path checks treat trailing dots or spaces, alternate data streams and NT namespace prefixes as the same location, and the file tools refuse NT namespace, UNC share and alternate-data-stream paths. The process ledger records the task that started a process, and a stopped turn now reports the processes that task started and that are still running, without stopping them. `kill_process` keeps its schema.
