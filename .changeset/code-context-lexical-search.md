Add `code_orient` action `context`: lexical (BM25 over identifier tokens) search over bounded line windows of the workspace source. Returns line ranges and masked, bounded snippets re-read from disk. A hit whose file changed since indexing triggers one rebuild and is never returned with the old range. A new, renamed, or deleted file is found on the next query, without waiting for the cache TTL; a query that does not concern a changed file runs at most one build step. A build that runs out of its time budget resumes on later queries until the index is complete; it is kept in memory only. A folder or file that cannot be read keeps its entries and keeps the view incomplete until it can be read again: a transient failure is retried every second, and one that persists is retried every 30 seconds after eight tries. Only the view stays incomplete; a catalog that waits on such failures is still trusted and expires on the normal clock. Nothing is reported complete silently. A file is read through one handle and checked against its path before and after the read, so a swapped link is refused. Symlinks and junctions are listed as links and not followed; a root that is a link, a denied name, or a path above the repository is refused. Secrets are masked by one owner, `src/memory/privacy-masking.ts`, for Memory writes and for snippets. A colon value is masked when it is credential-shaped or ends its field, so prose such as `credentials: read from the keychain` stays readable while `credentials: keychain` at a line end is masked. Basic-auth passwords (`-u`, `-U`, `-a`, combined flags such as `-sSu`, `--user`, `--proxy-user`, `--auth`) are masked on HTTP-client commands and on any command that is not a known non-HTTP tool, including backslash, `^`, and backtick continuations. URL passwords are masked with or without a user name. Literals on a line that assigns a secret word are masked, call arguments included, and a call keeps its callee. Compound key names, quoted, backtick, and typed assignments, command-line `--token` values, `Authorization` credentials, subscript keys such as `headers["x-api-key"]`, and PEM key blocks that span windows are masked too. Memory writes mask more than before: a bare value after `password`, `token`, or a similar key is masked, except type names and code references. Known limits: an unquoted value is cut at a space and at `& | ? , < > [ ] { }`; arrays, YAML block scalars, and multi-line triple-quoted values are not masked; Memory refuses, fail-closed, a kept reference that still looks credential-shaped. When the file list is cut, src, tests, and scripts are indexed before docs, and the cut is reported; the archived `.changeset/applied` tree is not indexed. Refuses a root inside a denied folder or above the repository, and a ref the working tree is not at. Reuses the memory identifier tokenizer, excludes runtime, secrets, protected folders, backups, junctions that leave the root, and key, env, or credential files, and reports skipped files by name. Telemetry and controller bookkeeping match the provider tools; context results are logged as metadata only. No embeddings, no network, no persisted state; the tool count is unchanged. First step of the Code Context Engine study (`docs/proposals/Code-Context-Engine-Steal-Use-Integration-Plan.md`).
