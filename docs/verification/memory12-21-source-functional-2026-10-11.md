## Measured diagnostic limits

Plan21 current and candidate each have retrieval **12 PASS and 4 FAIL**. The failures are `heldout-integrity-reconsolidation-a` and `heldout-integrity-reconsolidation-b`, each under native and external scripted controllers. The frozen oracle expects only `successor-a/b`; retrieval also selects untrusted `weak-a/b`. These are inherited retrieval-precision gaps, not designated expected-failure controls. The off arm is the negative control. Weak hypotheses remain unverified, and the scripted answer selects the verified successor, so the five integrity dimensions and outcome/use still pass. Candidate external-b reverses the two selected hits; no broader ranking gain/regression is inferred.

Complete sealed evidence means all required observations can be inspected and replayed. It does **not** mean every diagnostic dimension or all Plans12–21 acceptance gates pass. No oracle was rewritten to hide these gaps, and no retrieval tuning is included in this evaluation-only scope.

## Important implementation decisions

- Plan 12 resolves a plan ambiguity: handle-only requires expansion; stale or unknown existing checkpoint requires revalidation; a fresh absent checkpoint requires creation. `ready` says capsule continuity only. No read writes state or resumes paused/completed work.
- Plan 13 hashes the ordered exact available artifact-text array with existing disclosureDigest. Stable operation replay is idempotent; changed batch/payload/sequence conflicts. Cursor derives from the active episode's verified chain and receipts, never acknowledgment or timestamp.
- Plan 14 publication time is host-recorded in the same canonical semantic-mutation transaction. Old history remains unproven. Same-time order, backward clocks and corrupt watermark are explicit. Reads/startup do not publish the watermark or invent historical time. A stripped watermark with surviving v2 revision history becomes a canonical Memory initialization error; mutations refuse it without resetting state.
- Plan 15 project synthesis retains exact evidence claims through existing promotion. Historical knownAt synthesis is conservatively omitted where dependency currentness cannot be established. Nested source dependency currentness must be rechecked, not inferred from retained artifact availability.
- Plan 16 exact-target counterexamples/refinements remain persisted awaiting-verification proposals because the sink cannot atomically CAS that target. No target rewrite/retirement or Skill activation is claimed. Additive lessons still pass existing review/evidence gates; partial successes and retry identity survive.
- Plan 17 purpose is optional for legacy callers. Declared purposes enforce fact/outcome/procedure boundaries and evidence resolution; compaction preserves critical items and exact lineage. Controller-supplied verified working state remains rejected.
- Plan 18 rescheduling an active critical obligation uses correction-kind events, retaining item ID and refs. Explicit now/event keys produce a current-revision advisory projection; no timer, tool dispatch or completion is implied. Tiny budgets retain exact expansion handles or visible insufficient-budget responses.
- Plan 19 proposed feedback lacked exact node revision fields despite requiring stale rejection. Experiment-only sourceRevision/targetRevision were added, with tests. The oracle remains separate from candidate inputs, and existing independent retrieval arithmetic is reused. No production graph mutation API accepts these proposals.
- Plans 20/21 use original fixtures; unknown/missing/failed evidence must remain visible. Scripted controller labels do not represent actual model execution, and integrity failures cannot be averaged into acceptance. Independent replay proves evidence consistency, not cryptographic authenticity that an execution occurred. The final reviewer reproduced and closed recall/answer continuity, cross-phase diagnostic substitution, support-source substitution and failed-run packaging defects; unchanged valid fixtures remain accepted.
