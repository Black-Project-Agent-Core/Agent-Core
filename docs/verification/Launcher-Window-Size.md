# Launcher window size

2026-10-29. The user requested working window-size presets, editable dimensions, and persistence across a complete launcher exit and restart.

The WinForms launcher is the size owner. On a fresh install with no saved size it starts at **1202 × 811 px**; opening the dialog only reads the actual outer window size and does not resize it. A preset or Reset Default applies immediately, while manual dimensions apply through Apply. The host returns the actual resulting size and an error if persistence fails. OS-enforced minimum window dimensions are reported to the dialog; there is no extra 940 × 560 application minimum.

`runtime/launcher/window-size.json` stores only versioned width and height through the existing atomic file owner. Explicit preset/manual changes save immediately; an ordinary native resize saves at ResizeEnd. A maximized/minimized window does not overwrite its normal size. Invalid/corrupt files are preserved and produce a warning; saving a valid user choice can replace the invalid settings. Existing Agent Core icon, host authentication boundaries and other backend behavior remain unchanged.
