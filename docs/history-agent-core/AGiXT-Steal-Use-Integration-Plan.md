## 3. Approved AGIXT-P1 contract

Add optional `read_file.options.networkPolicy: 'public-only'`. Absence retains the existing URL behavior. Any other supplied value, or using this option with a local-file read, is an explicit error rather than an ignored safety request. This is a per-call restriction of one tool, not a gate on machine control, Memory or other network clients. Existing credential/tool grants still apply unchanged.

**Admission:** HTTP/HTTPS only; maximum input URL 4,096 characters. Reject userinfo, backslashes, malformed/ambiguous host literals and zone identifiers. Version 1 uses only default HTTP/HTTPS ports (80/443); other ports are explicitly unsupported, not silently rewritten. Normalize addresses before classification, including IPv4-mapped IPv6. Private, loopback, link-local, multicast, unspecified, documentation/test and other special/non-global ranges are denied by a deterministic conservative classifier. Unsupported address representations fail closed. Do not use DNS suffixes, a successful HEAD request, or `is_safe_url` alone as proof of connection safety.

**Connection:** resolve the hostname once per hop, validate every returned address, choose one admitted address, and bind the actual socket to it. Preserve the original hostname for Host, TLS SNI and certificate verification; never disable TLS validation. Verify the connected peer matches the selected address. Do not reuse an unproven pooled socket, re-resolve at connect, use an environment proxy, send caller cookies/Authorization headers, or fall back to unrestricted fetch. Reject an address set containing even one disallowed candidate. The stricter policy's initial implementation performs one send per hop, not automatic request retries.

**Redirects and limits:** at most five redirects, six sends total, with fresh validation/pinning for every hop including relative Locations. Abort on missing/invalid Location, a disallowed destination or a scheme change outside HTTP/HTTPS. Use one 30-second end-to-end deadline including resolution/body consumption and caller cancellation; delayed resolver completions must never open a socket after cancellation. Close each response/socket on redirect, refusal, overflow or abort. Bound response headers to 16 KiB. Request identity encoding and reject non-identity response encoding in version 1 instead of accidentally permitting unbounded decompression.

**Payload/format scope:** cap downloaded bytes at the lesser of the existing format-specific limit and 10 MiB. Preserve the existing MCP output budget. Version 1 supports text/JSON/HTML as inert text, common raster images (PNG/JPEG/GIF/WebP), and PDF via the existing byte-taking parser. It does not execute HTML, fetch embedded resources, expand arbitrary archives, or invoke a URL-taking converter. In this mode an omitted projection means this native byte path; explicit `projection:'native'` is accepted, other projection modes and unsupported binary types are refused with a reason. Ordinary reads without the policy keep their original auto-projection contract. A later expansion can add a converter only after proving it operates on bytes without further network access.

**Evidence and errors:** expose bounded `networkPolicy='public-only'`/hop-count/bytes metadata and sanitized failure codes, not credentials, full query strings or raw response headers. A successful public-address check is not content-trust, malware safety, authorization to follow page instructions, or a guarantee about the remote operator. Network/address errors must remain errors; never return an empty object as if the fetch succeeded. No automatic original-tool replay.
