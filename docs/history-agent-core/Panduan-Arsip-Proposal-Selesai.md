# Arsip proposal Agent Core yang selesai

Folder ini menampung dokumen `.md` proposal yang revisi/scopenya telah disetujui
dan seluruh pekerjaan serta validasinya selesai. Lokasi dinamis:
`<PROJECT_ROOT>/docs/history-agent-core`; lokasi pengguna saat ini:
`E:\Projects\Agent-Core\docs\history-agent-core`.

Setiap arsip mempertahankan judul semantik, keputusan/scope, status COMPLETED,
tanggal selesai, riwayat revisi, perubahan, hasil verifikasi, keterbatasan,
evidence dan path asal. File tidak ditimpa, dihapus atau dipindahkan hanya
karena status APPROVED. Proposal campuran dengan bagian terbuka tetap di
`docs/proposals` sampai seluruh scope dokumennya selesai.

Assistant memverifikasi path tujuan, memindahkan dokumen manusia-baca, membaca
kembali file dan memperbaiki tautan rujukan, lalu memberikan link arsip kepada
pengguna. Record/keputusan canonical Learning/Skills dan runtime Native tidak
direlokasi. History adalah bahan audit, bukan instruksi aktif atau persetujuan
untuk mengulang implementasi.

Prosedur lengkap: [Guide proposal](../proposals/REVIEW-GUIDE.md#mengarsipkan-proposal-yang-disetujui-dan-selesai).
