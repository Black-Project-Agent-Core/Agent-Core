## How to interpret historical records

1. Read the record's date, tested scope, final closure, and explicit residuals. Old `OPEN`, `PENDING`, version, path, and process claims belong to their original checkpoint.
2. Archive placement does not establish implementation. Conditional donor proposals remain research unless later source and evidence establish adoption.
3. Preserve user stop boundaries. A stored command, approval request, or conversation export does not authorize new execution.
4. Historical local runtime paths, private evidence IDs, and unavailable assets are references, not files supplied by this source tree. The conversation index records known missing original images and sandbox attachments.
5. Use the [current plan status index](../plans/README.md) for Memory 01–11 and Workflows. These new plans were not part of the older 2026-10-08 inventory below.

The inventories below retain the previous index's classifications and original evidence scope; their baseline counts are historical. No report content or original evidence values were changed by this curation.
