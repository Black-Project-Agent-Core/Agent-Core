# Inventaris kemampuan Hermes (read-only)

Sumber: repo Hermes Official, root tidak ditulis sebagai path drive di dokumen ini; semua path bukti relatif terhadap root repo itu.

Metode: baca `website/docs/` dan kode di root Hermes. Repo itu tidak diubah, dan tidak ada program dari repo itu yang dijalankan. Setiap baris menunjuk path yang sudah dibuka atau dicari di sesi ini. Path bukti diperiksa keberadaannya secara otomatis; isi baris diperiksa sebagian (lihat status per area).

Legenda kolom terakhir:
- Inti: harus dimiliki Agent Core agar menggantikan Hermes sepenuhnya.
- Tambahan: pelengkap.

Status per area:
- A Entry: ditulis subagen; semua path bukti diperiksa keberadaannya; isi belum diperiksa baris per baris.
- B Gateway pesan: ditulis subagen; semua path bukti diperiksa keberadaannya; isi belum diperiksa baris per baris.
- C sampai H, L: ditulis dan dibuka sendiri.
- I, J, K, M: ditulis dan dibuka sendiri; path bukti diperiksa keberadaannya.
- Baris `(sisa area) | belum diperiksa` menandai bagian yang belum dibuka.

Batas:
- Inventaris ini memetakan kemampuan dari dokumen dan kode. Ini bukan verifikasi runtime.
- Bila dokumen dan kode berbeda, konflik ditulis di baris terkait, bukan dipilih salah satu.
- Tidak ada baris yang dibuat dari ingatan tanpa path bukti.
