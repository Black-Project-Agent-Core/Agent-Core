## 6. Embedding, retrieval, dan representasi aljabar linear

**Provider live:** cloudflare-workers-ai, model @cf/google/embeddinggemma-300m, 768 dimensi, dengan client Node memakai HTTPS ke Cloudflare (src/index.ts:75-84; embedder.ts:4-22,71-142; memory_status). **Embedding inference berada di layanan eksternal, bukan terbukti berjalan di GPU lokal.** API credentials tidak dibaca/dicantumkan.

**Dua bentuk chunking yang tidak boleh tertukar:**
- src/memory/embedder.ts:20-70 menormalisasi document dan memecah maksimal **6 chunk × 1600 karakter**, API batch maksimal 32. Output tiap chunk dinormalisasi, dirata-rata, lalu dinormalisasi lagi sehingga satu record punya satu vector.
- src/memory/passages.ts:5-49 mendefinisikan window **600 codepoint, overlap 80, maksimal 128 passage**. Akan dipakai jika indexGranularity=passage. **Indeks live saat ini v3 record granular**: file runtime/memory/index/index.json 5,877,213 byte, 212 entries, 212 embeddings, **0 passages**, semanticDocumentVersion=2, builtAt 2026-10-16T15:47:33.697Z. Jadi passage indexing **ada di source, bukan terbukti aktif** di runtime.

**Cosine:** src/memory/embedder.ts:145-167 melakukan scale-aware dot/norm:
\[
\operatorname{cos}(q,d)=\frac{\sum_i q_i d_i}{\sqrt{\sum_i q_i^2}\sqrt{\sum_i d_i^2}}
\]
Skor terbatas pada [-1,1]. Normalisasi L2 memungkinkan menghitung dot pada vektor normal, namun implementasi cosine tetap memeriksa panjang/norma secara eksplisit.

**BM25:** src/memory/bm25.ts:23-66 memakai k1=1.2, b=0.75, IDF = ln[1+(N−df+0.5)/(df+0.5)], lalu membagi skor per dokumen dengan skor maksimum hasil query. Weight BM25=0.9 untuk 1–2 keyword bermakna, selain itu 0.45; stopword Inggris/Indonesia (bm25.ts:4-20).

**Legacy additive score:** src/memory/retrieval.ts:116-190 menjumlah exact phrase (4), token overlap (hingga 3), keyword/tag/context/category, cosine terpotong [0,1] dikali 4, BM25×weight, sourceFileMatch, recency hingga 0.05, linkBoost. Angka ini adalah **heuristic ranking relevance**, bukan probabilitas benar maupun manfaat riil terhadap hasil task.

**Fusion:** src/memory/retrieval.ts:275-582 menggabungkan channel lexical/metadata/semantic/source melalui Reciprocal Rank Fusion k=60:
\[
RRF(d)=\sum_{c:d\in c}\frac{1}{60+\operatorname{rank}_c(d)}
\]
Threshold awal 20% top-RRF, dengan exception untuk bukti kuat pada beberapa channel. Kemudian MMR lambda=0.8:
\[
S(d)=0.8\,relativeRRF(d)+0.2(1-redundancy(d))+feedbackInfluence(d)
\]
Redundancy vector cosine bila tersedia, selain itu bounded lexical Jaccard; source mempunyai maxCandidates=256, maxCodepoints=8192, maxUniqueTokens=512, maxLexicalPairs=8192 (retrieval.ts:26-34,372-438). Feedback influence = clamp[(salience−1)×0.08, −0.06,+0.08], hanya dipakai pada fusion (retrieval.ts:285-310; service.ts:1342-1348).

**Eligibility dan failure:** service.ts:1315-1334 menolak/menahan expired, forgotten, superseded, v2 archived, unsupported/stale synthesis dan workspace lain dengan pengecualian pinned. V2 recall memungkinkan validAt/knownAt dan menunjukkan conflict/applicability/freshness (controller-session.ts:125-225). src/memory/index.ts:71-133,169-178,230-324 memeriksa provider/model/dimensi, fingerprint dan finite entries; vektor salah tidak boleh dicampur diam-diam, index bisa refresh/rebuild. Query embedding failure direkam degraded dan lexical retrieval masih punya fallback (service.ts:1335-1348), sedangkan src/memory/embedding-repair.ts menyimpan pending/failed state. Retry provider dibatasi (embedder.ts:82-121). Skor similarity, epistemic confidence, dan verified usefulness adalah **tiga variabel berbeda**.

## 9. Retention dan akumulasi kontribusi kejadian (analogi integral terbatas)

**Rumus aktual** dari src/memory/retention-score.ts:5-40:
\[
R=S\,e^{-0.02 t_u}+0.6\,\ln(1+N)\,e^{-0.04 t_a}
\]

Di sini t_u adalah hari sejak updatedAt (bukan createdAt); N = retrievalCount integer non-negatif; t_a adalah hari sejak lastAccessedAt, jika tidak pernah diakses seluruh access term = 0; S = salience clamp [0.25,2], default 1. Kedua faktor waktu memakai max(0, elapsed days). Threshold review default = **0.2** (retention-score.ts:5-40; service.ts:687-759).

Feedback ordinary (src/memory/feedback.ts:9-64,190-267): helpful menaikkan S **+0.25**, not-helpful menurunkan **−0.25**, stale/wrong mengatur ke minimum **0.25**. Event memiliki eventId, kind, at dan optional contentDigest; lifecycle forget/restore memiliki timestamp. Store bounded MAX_RECORDS=512 dan MAX_EVENTS_PER_MEMORY=64. Retrieval access punya counter, lastAccessedAt dan bounded evolutionHistory. Sistem **menyimpan sejumlah peristiwa bertimestamp**, bukan hanya total counter, tetapi **rumus R tidak mengintegrasikan riwayat keberhasilan/gagal, kepastian atau independensi sumber secara langsung**.

Feedback ranking: src/memory/retrieval.ts:285-310 memakai fusion feedbackInfluence yang terbatas, tidak semua ranking profile. Feedback pada source karenanya bisa memengaruhi fusion dan retention jika dicatat; pada live snapshot **feedback.recordCount=0** (memory_status), sehingga efeknya untuk record tertentu **belum terbukti sedang terjadi**. Use outcome receipts dan generic Learning verification tidak otomatis masuk sebagai faktor matematis R.

Retirement: src/memory/service.ts:687-759 menandai low-retention (<threshold), explicit stale/wrong, unretrieved inactivity ≥30 hari, expired, forgotten, typed contradiction. Preview read-only memory_retirement_review(limit=3) mengembalikan mode=preview, mutatesMemory=false, candidates=[]. **Tidak menemukan kandidat dalam batas ini bukan bukti tidak ada kontradiksi, atau semua data harus disimpan selamanya.** SetRetention eksplisit pada episodes.ts:497-529 mempunyai archival tier terpisah dari feedback visibility dan physical deletion. Deletion nyata terlindung oleh pinned/v2 history preservation.
