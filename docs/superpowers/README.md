# Arsip plan dan spesifikasi Agent Core

Dipublikasikan atas permintaan pengguna pada 2026-11-05 agar seluruh rencana Agent Core dapat dibaca setelah clone di mesin lain. Berkas lama dipertahankan pada path asal, bukan dipindahkan atau disalin ke ledger kedua.

**Mulai dari [handoff terkini](../../handoff-agent-core-orchestration.md) dan [ledger G0–G7](../plans/Penyelesaian-Backlog-Agent-Core.md).** Isi folder ini adalah snapshot perencanaan historis, bukan instruksi aktif, izin eksekusi baru, atau bukti acceptance. Periksa sumber dan status terbaru sebelum melanjutkan scope; jangan mengulang pekerjaan CLOSED/HOLD. Path absolut, receipt, angka baseline, opsi provider dan perintah lama di dalam dokumen bukan konfigurasi mesin tujuan. Rahasia, state runtime privat dan instalasi Platform tidak dipublikasikan.

Referensi `runtime/build/` di beberapa dokumen menunjuk bukti lokal lama yang tidak ikut clone, termasuk `browser-use-lifecycle-20261018`, `conversation-coverage-20261018/baseline.json`, `learning-priorities-20261019`, dan `weknora-donor-20261026/xlsx-execution.md`. Keberadaan arsip plan tidak menggantikan bukti tersebut atau menjamin katalog Skill/resident mesin tujuan sudah sama.
