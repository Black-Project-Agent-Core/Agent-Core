## Changes

- **06:** Abstract recall includes an exact canonical content span and semantic revision; `abstract` is the exact alias of `excerpt.text`. Map and legacy search projections stay unchanged. Selector-version changes stale old cursors. Full response budgets include all proof fields.
- **07:** Host-only passage granularity derives bounded overlapping children, max child semantic ranking and parent-only results. Canonical scope/revision/retention remain parent-owned. Compatible default record format3 indexes are reused without a forced embedding rebuild; passage opt-in uses format4 and explicit coverage. Retry-state admission stays bounded without evicting failed-child history.
- **08:** Host-only volatile query-vector cache supplies bounded LRU/bytes/TTL and singleflight, exact query/identity keys, caller-isolated vectors and local cancellation/disposal. Every request still checks canonical corpus and eligibility. It caches no recall results, permission or trust decisions.
- **09:** An opt-in pure helper and documented controller protocol bound root/subquestion recalls, expansion calls, bytes and dispatch time. Exact revision/provenance merges preserve conflicts and visible gaps. Actual host examples use `memory_v2_read` with top-level `scope.taskId`; no new planner model or MCP wrapper is added.
- **10:** Host-only relevance abstention evaluates content lexical evidence and the same call's semantic availability before paging. Metadata, recency and pinned status alone cannot bypass the content gate. Semantic representation can include existing allowed metadata, and semantic support is not factual truth. Default policy remains absent.
- **11:** Bounded NFC exact/subword identifier tokenization is shared by overlap and BM25. Camel/acronym/path/digit boundaries remain visible before lowercasing; concrete identifier eligibility stays conservative. Compound-query token counts intentionally affect existing BM25 weight selection. Intelligence/consolidation tokenization and semantic document version2 remain unchanged.

Passage granularity, query caching and relevance policy remain disabled by default and are not exposed as public tool-input settings. The lexical tokenizer and additive excerpt are source behavior changes. Their existing ranking/request bindings make incompatible continuation stale; restart recall rather than forcing an old cursor.
