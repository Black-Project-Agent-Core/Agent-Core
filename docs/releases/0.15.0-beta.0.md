# Agent Core 0.15.0-beta.0

Date: 2026-10-09 UTC. Channel: **source prerelease**. Target stable: **0.15.0**. Previous stable source baseline: **0.14.0**.

## What this contains

- External-controller read-only `image_inspect` overview/crop/zoom with original-pixel provenance, bounded image delivery and session-bound views.
- Memory 01 filtered semantic retrieval and revision-race checks in the pinned internal Memory engine.
- Unified System + Memory Workflows canvas, using a pinned offline Archify viewer. The canvas describes static source dependencies; it does not prove runtime execution or Memory quality.
- Prerelease version synchronization, retained release intents, packaging fixes and explicit version/publication/handoff policy.
