# Agent Core 0.15.0 — Windows x64

Status: release preparation; stable publication is pending final verification and package acceptance. Date: 19 October 2026 (Asia/Bangkok).

## Release scope

This release consolidates the current external-controller source line. It adds scoped Memory continuity and claim review, bounded recall waiting, background Open Browser Use and owned conversation reading, readable proposal cards and guides, and the current Workflows diagrams. Native-specific code remains frozen; this release does not enable new Native capabilities.

The portable ZIP includes a self-contained Windows launcher, local Node runtime, compiled Core/UI, approved provider binaries, fresh foundational Memory text, source and license evidence, and a SHA-256 integrity manifest. Credentials, user Memory, browser profiles and operational state are excluded. Configure providers, authentication, extension permissions and the tunnel separately.

## Scoped readiness corrections

- Release intent archival preserves both root and Memory-domain histories under valid paths.
- Source-only prerelease promotion uses an explicit, exact-version exit receipt; no old artifact sequence is invented.
- Static proposal/Raka guides, README and the exact browser transport/source are shipped, without copying browser sessions or profiles.
- The previously published Skills writer/activation recovery correction is reconciled with the authoritative local source, preserving both repository histories and local changes. Windows regression acceptance is pending.

## Verification

Recorded evidence belongs in `runtime/build/stable-release-20261019`; runtime evidence is local and is not shipped as private state.

- Full root suite: running; failures must be resolved or explicitly scoped before stable promotion.
- Full UI suite: 24 passed, zero failed. UI typecheck: passed using its own installed TypeScript.
- Focused release suite: 21 passed; demonstrated failing regressions preceded the fixes.
- Core/UI/launcher package builds, ZIP boundary/integrity checks, isolated runtime acceptance and remote release readback: pending.

## Known boundaries

Stable acceptance is limited to the documented Windows external-controller scope. Browser conversation coverage is the loaded DOM, with incomplete history declared. Optional providers/devices require configuration and separate evidence. Claim reviews are controller assessments, not proof that all stored facts are true. No benchmark of cumulative learning or intelligence is claimed. Unsupported filesystem privileges are skipped explicitly, never counted as passes.
