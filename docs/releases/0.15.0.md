## Package and installation

The ZIP includes a self-contained Windows launcher, local Node, compiled Core/UI, approved provider binaries, two curated Skill artifacts, current guides, source for audit and license notices. `SHA256SUMS.txt` and the per-file integrity manifest bind its bytes. Use the exact repository commit for a complete development checkout.

For a new installation with no existing Memory, run bundled Node against `scripts/memory/activate-canonical.mjs --fresh` while Core is stopped, then launch `Agent Core.exe`. Generic `MEMORY-BOOTSTRAP.md` stays outside the canonical store. No activation marker, user Memory, credential, browser profile, private tooling link or operational state is shipped. Existing installations require explicit migration/recovery, not extraction over a running store.

REA instructions and lockfiles are included; optional CLI dependencies on a new computer require explicit restoration in the [engineering guide](../External-Engineering-Skills.md). Configure authentication, providers, extension permissions and the tunnel separately.
